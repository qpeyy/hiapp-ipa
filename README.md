# HiApp

Minimal iOS app for sideloading via AltStore/AltServer.

## Get the IPA

1. Go to **Actions** tab on GitHub
2. Click the latest successful run
3. Download the **HiApp-ipa** artifact (a zip)
4. Unzip it — you'll get `HiApp.ipa`

## Sideload with AltServer

1. Install [AltServer](https://altstore.io) on your PC/Mac
2. Connect your iPhone via USB
3. Open AltServer → Install AltStore on your device (one-time setup)
4. Open AltStore on your iPhone → tap **+** → select `HiApp.ipa`
5. Sign in with your Apple ID when prompted — AltStore re-signs it for you
